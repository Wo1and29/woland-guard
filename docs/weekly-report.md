# Еженедельный отчёт

Агрегатный отчёт за семь суток. Формируется явной локальной командой и печатается в stdout —
файл создаёт оператор перенаправлением ([ADR-0023](adr/0023-weekly-report.md)).

```bash
docker compose exec control-plane woland-guard-admin weekly-report \
  --week-ending 2026-08-07 > report.md
docker compose exec control-plane woland-guard-admin weekly-report \
  --week-ending 2026-08-07 --format html > report.html
```

## Период

`--week-ending 2026-08-07` означает окно **[2026-07-31 00:00 UTC, 2026-08-07 00:00 UTC)** —
ровно семь суток, конец не включён. Полуинтервал выбран намеренно: два соседних отчёта не считают
события на стыке дважды.

Инцидент относится к периоду по моменту открытия (`created_at`), а не по последнему evidence:
иначе давний инцидент, получивший новое подтверждение, считался бы открытым заново. События —
по моменту на хосте (`occurred_at`).

## Что входит

| Раздел | Содержание |
|---|---|
| Наблюдаемые серверы | всего, активных, неактивных |
| Инциденты за период | всего и по каждой severity, включая нули |
| По правилам | сколько инцидентов открыло каждое правило |
| Изменения статусов | сколько переходов в каждый статус за период |
| Открытые инциденты | по severity, **на момент формирования** |
| Принятые события | всего и по источникам |

Severity с нулевым значением печатается явно: пропуск строки читался бы как «не измеряли»,
а `0` читается как «измеряли, не нашли».

## Чего в отчёте нет намеренно

- **IP-адресов.** Отчёт может уходить заказчику, а адрес легитимного пользователя с динамическим
  IP — персональные данные наравне с адресом сканера. Оператор видит адреса в дашборде и в самом
  инциденте, где они и нужны для расследования.
- **Строк событий, путей, correlation.** Отчёт агрегатный: выгрузка событий вынесла бы наружу
  атрибуты (например, пути Nginx), которые собираются только при условии, что остаются внутри
  системы (ADR-0020 §2).
- **Имён операторов.** Считаются переходы статусов, а не кто их сделал; аудит остаётся в
  дашборде.

## PDF

PDF получается печатью из HTML-формата (`Ctrl+P` → «Сохранить как PDF»), библиотекой не
генерируется. Причина в ADR-0023 §3: PDF-библиотека потребовала бы новой зависимости **и**
встроенного TTF-шрифта с кириллицей в репозитории (базовые шрифты PDF покрывают только Latin-1),
тогда как браузер печатает лучше, бесплатно и без новой поверхности разбора текста.

HTML свёрстан под печать: A4, поля, запрет разрыва таблиц между страницами.

Решение отложенное, а не окончательное: если понадобится `одна команда → PDF` без участия
человека, зависимость и шрифт добавляются отдельным ADR.

## Ограничения, которые отчёт печатает сам

Каждый отчёт содержит раздел «Как читать этот отчёт». Это не формальность: отчёт читает заказчик,
и он не должен выглядеть как заключение об отсутствии проблем.

- счётчики отражают только то, что агент успел доставить — разрыв в журнале (`journal_gap`)
  в отчёт не попадает;
- отсутствие инцидентов не означает отсутствия атак, а означает, что ни одно из настроенных
  правил не сработало;
- событие, доставленное с задержкой, попадёт в отчёт своей недели, а порождённый им инцидент —
  в отчёт недели доставки;
- открытые инциденты посчитаны на момент формирования, а не на конец периода: система хранит
  текущий статус, а не историю состояний на произвольную дату;
- доступность серверов не проверяется и не выводится.
